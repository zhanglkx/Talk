### M6-S01 详情

- 来源：任务卡 M6-T01。
- 计划：接真实模型前先定两件事。一是代码里的模型只是一个接口（ModelAdapter），离线测试可以换成假实现，不花钱、不依赖网络；二是把供应商的访问方式、数据政策、价格和预算写成记录，作为之后能否发起真实调用的依据。
- 动作：
  1. 定义 ModelAdapter 接口：输入只有问句、工具 Schema 和时区；输出是待校验的规划；支持取消（abort）。
  2. 写返回固定规划的假实现，供离线测试使用。
  3. 记录模型 ID、数据保留与是否用于训练、价格及价格日期、预算上限、密钥的环境变量名。
- 注意事项：
  - 接口输入里不出现账本数据、`userId` 或 SQL：模型只负责规划，授权、计算和回答都由服务端完成。
  - 价格用精确十进制或最小计费单位，并记下价格日期；政策或价格没核实就不做真实调用，不借公司账号绕过。
  - 本步不发起真实调用；首次真实调用前必须先配置总 deadline 和 token 上限。
- 验收：
  1. `pnpm typecheck` 通过；假实现的单元测试能拿到固定规划，并能被 abort 取消。
  2. 代码审查确认接口输入类型中没有账本数据和 `userId`。
  3. 供应商记录齐全，仓库中没有真实密钥。
