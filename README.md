# 星河报销｜企业费用报销系统（全栈学习项目）

用虚构数据练习企业级全栈开发：员工提交报销单 → 部门主管审批 → 财务审核打款。前端 React + Ant Design，后端 NestJS + PostgreSQL，按业务需要逐步引入 Redis、Nginx、Docker 和 AI。

不是真实的财务系统。代码、测试、文档和日志里只出现虚构的公司、员工和金额。
